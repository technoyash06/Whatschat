WhatsChat V15 - Reliable Voice and Video Calls

No Node.js installation is needed.

START
Double-click 1_OPEN_WHATSCHAT_V15.cmd and keep its window running.

GROUPS
Use CREATE GROUP to add several registered usernames. Use MY GROUPS to list group codes, open a group, add members, leave, or delete a group you own. Group messages are stored for offline members.

MEDIA AND CALLS
MEDIA, VOICE, and VIDEO work in direct and group chats. Group members answer or decline separately; only people who answer join, and all-declined calls end. The call platform includes screen sharing.

CALL CONNECTION FIX
Calls try peer-to-peer media first. If that cannot connect, WhatsChat automatically relays live audio/video through the same gateway. Click FIX CONNECTION to switch immediately, START SOUND if incoming audio is blocked, or ENABLE MIC/CAMERA after granting browser permission. Relay media is not saved.

STOP
Double-click 2_STOP_WHATSCHAT_V15.cmd.

The launcher replaces outdated WhatsChat servers on port 8080, so the new project will not silently open an older version.

You cannot get blocked or anything.
